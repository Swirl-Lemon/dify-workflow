# 两个提示词文件输出字段对比分析

## 一、订单明细表字段对比

### 文件1：组装json&回写prompt(4.13).md
| 客户商品名称 | 客户商品规格 | 内部商品名称 | 内部物料编码 | 商品类型 | 品牌 | 规格 | 型号/等级 | 单价 | 数量 | 单位 | 备注 | 期望发货日期 |

### 文件2：组装json&回写prompt.md
| 客户名称 | 客户商品名称 | 内部商品名称 | 内部物料编码 | 商品类型 | 规格 | 品牌 | 型号/等级 | 单价 | 数量 | 单位 | 备注 | 期望发货日期 |

### 差异分析：
1. **文件1多了**：
   - 客户商品规格（第2列）

2. **文件2多了**：
   - 客户名称（第1列）

3. **字段顺序不同**：
   - 文件1：客户商品名称 → 客户商品规格 → 内部商品名称...
   - 文件2：客户名称 → 客户商品名称 → 内部商品名称...

4. **品牌和规格顺序不同**：
   - 文件1：品牌 → 规格
   - 文件2：规格 → 品牌

## 二、订单摘要/其他信息表字段对比

### 文件1：组装json&回写prompt(4.13).md
| 客户 | 客户名称 |
| 支付方式 | 支付方式内容 |
| 结算方式 | 结算方式内容 |
| 发票类型 | 发票类型内容 |
| 配送方式 | 配送方式内容 |

### 文件2：组装json&回写prompt.md
| 订单信息 | 内容 |
| 支付方式 | 支付方式内容 |
| 结算方式 | 结算方式内容 |
| 发票类型 | 发票类型内容 |
| 配送方式 | 配送方式内容 |

### 差异分析：
1. **表头不同**：
   - 文件1：第一行是"客户 | 客户名称"（单独显示客户信息）
   - 文件2：第一行是"订单信息 | 内容"（统一的表头）

2. **订单备注说明不同**：
   - 文件1：仅显示"订单备注内容"
   - 文件2：明确要求"订单备注内容必须包含特殊商品备案信息，与订单编号或者合同编号合并显示"

## 三、总结

### 主要区别：

1. **订单明细表**：
   - 文件1包含"客户商品规格"字段，文件2不包含
   - 文件2包含"客户名称"字段，文件1不包含（客户名称在订单摘要中单独显示）
   - 品牌和规格的列顺序不同

2. **订单摘要表**：
   - 文件1第一行单独显示客户信息（客户 | 客户名称）
   - 文件2使用统一的表头（订单信息 | 内容）
   - 文件2对订单备注有更明确的要求说明

3. **字段总数**：
   - 文件1订单明细表：13个字段（含客户商品规格）
   - 文件2订单明细表：13个字段（含客户名称）

### 建议：
- 如果需要保留客户商品规格信息，建议采用文件1的格式
- 如果需要客户名称在明细表中显示，建议采用文件2的格式
- 订单备注的说明建议采用文件2的明确要求
